Built in one night

A radar for the whole sky.

SkyWatch puts every plane in the air on one live map: more than ten thousand of them, gliding in real time. Click any plane and a Claude agent goes out on the live web through Bright Data, then comes back with its airline, route and aircraft, sources included. I built it at the Claude Code Build Night: Research with Web Data in San Francisco.

Watch the demo Read the source

Claude does the thinking, Bright Data does the looking, and a single canvas keeps ten thousand planes smooth. Built at San Francisco | Claude Code Build Night.

A game, in one evening.

Robin Hoodwinked is a silly medieval archery game I built with Claude Code at a Claude Community Build Day in San Francisco. Someone stole the King's pie. The thief always lies, everyone else tells the truth, and you settle it with a bow.
